# Smart Keyboard AI - لوحة المفاتيح الذكية

تطبيق لوحة مفاتيح أندرويد ذكي مع تصحيح تلقائي وتحسين أسلوب النصوص العربية باستخدام الذكاء الاصطناعي.

## 🌟 الميزات

### 1. التصحيح التلقائي ✅
- تصحيح الأخطاء الإملائية تلقائياً
- تصحيح الأخطاء النحوية
- الحفاظ على المعنى الأصلي
- معالجة فورية أثناء الكتابة

### 2. الصياغة الأدبية ✍️
- تحسين الأسلوب الأدبي للنصوص
- كتابة بليغة وفصيحة
- أسلوب احترافي يشبه الكتّاب المحترفين
- تحسين الجمل والتراكيب

### 3. لوحة مفاتيح عربية كاملة 🔤
- جميع الحروف العربية
- أرقام وعلامات ترقيم
- دعم كامل للغة العربية
- تصميم حديث وسهل الاستخدام

### 4. تكامل الذكاء الاصطناعي 🤖
- استخدام Claude AI API
- معالجة ذكية للنصوص
- تعلم من السياق
- نتائج دقيقة وموثوقة

### 5. إعدادات متقدمة ⚙️
- تفعيل/تعطيل التصحيح التلقائي
- تفعيل/تعطيل تحسين الأسلوب
- إدارة مفتاح API
- تخصيص التجربة

## 📱 المتطلبات

- **نظام التشغيل**: Android 7.0 (API 24) أو أحدث
- **الذاكرة**: 100 MB على الأقل
- **الاتصال**: إنترنت نشط (لاستخدام AI)

## 🚀 البدء السريع

### التثبيت:
1. حمّل ملف `app-debug.apk` أو `app-release.apk`
2. انسخه إلى هاتفك
3. افتح الملف واضغط **تثبيت**
4. فعّل **مصادر غير معروفة** إذا لزم الأمر

### التفعيل:
1. افتح التطبيق
2. اضغط **تفعيل لوحة المفاتيح**
3. اذهب إلى الإعدادات → اللغات والإدخال → لوحات المفاتيح
4. اختر **Smart Keyboard AI**

### الاستخدام:
1. افتح أي تطبيق (WhatsApp, Gmail, إلخ)
2. اضغط على حقل الإدخال
3. اختر **Smart Keyboard AI** من لوحات المفاتيح
4. ابدأ الكتابة!

---

## 🛠️ البناء من المصدر

### الطريقة الأولى: Android Studio (الأسهل)

1. **تحميل Android Studio**:
   - اذهب إلى: https://developer.android.com/studio
   - حمّل وثبّت البرنامج

2. **استيراد المشروع**:
   - افتح Android Studio
   - اختر **File → Open**
   - اختر مجلد `SmartKeyboardAI`

3. **بناء APK**:
   - اذهب إلى **Build → Build Bundle(s) / APK(s) → Build APK(s)**
   - انتظر حتى ينتهي البناء
   - ستجد APK في: `app/build/outputs/apk/debug/`

### الطريقة الثانية: سطر الأوامر

```bash
# استنساخ المشروع
git clone https://github.com/Osama1348/SmartKeyboardAI.git
cd SmartKeyboardAI

# بناء APK
./gradlew assembleDebug

# ستجد APK في:
# app/build/outputs/apk/debug/app-debug.apk
```

### إضافة مفتاح API:
1. احصل على مفتاح Claude API من: https://console.anthropic.com

4. أدخل مفتاح API الخاص بك

- **تحسين الأسلوب**: فعّل لتحسين الأسلوب الأدبي

## 🔧 التكنولوجيات المستخدمة

- **Kotlin**: لغة البرمجة الأساسية
- **Android SDK**: إطار عمل أندرويد
- **Retrofit**: لـ API calls
- **Coroutines**: للعمليات غير المتزامنة
- **Claude AI API**: للمعالجة الذكية
